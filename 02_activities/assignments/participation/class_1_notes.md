# Class 1 Notes - Data Visualization

## Why data visualization matters
Data visualization helps communicate insights clearly. Historical examples like John Snow and Florence Nightingale show that visualizations can influence decisions and even save lives.

## What makes good visualization?
A good visualization should be:
- Aesthetic (looks clean and readable)
- Substantive (accurately represents data)
- Perceptual (clearly communicates a message)

## What I learned about matplotlib
- A figure contains axes
- The axes is the actual plot
- We can modify colors, markers, line styles, labels, and fonts
- Visualization requires decision-making based on context and audience
