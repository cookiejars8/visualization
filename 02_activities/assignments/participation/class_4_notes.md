## Accessible data viz
- accessibility matters b/c some people literally can’t read the chart
- example in slides: “daily routines” looked good but colourblind ppl can’t tell the colours apart + no labels so it becomes useless :contentReference[oaicite:2]{index=2}

### colour stuff
- colour has channels:
  - luminance (brightness)
  - saturation (how colourful)
  - hue (identity) :contentReferenc
- hue good for categories but shouldn’t rely on colour only
- contrast matters (higher contrast easier to tell apart) :contentReference[oaicite:6]{index=6}
- can use viridis colormap b/c it works better for colourblind + grayscale print :contentReference

### text + labels
- labels + legends help reduce confusion / anxiety :contentReference[oaicite:9]{index=9}
- font: try to use readable fonts (sans serif often better), and don’t use too many fonts :contentReference[oaicite:10]{index=10}
- font size like 12+ if possible :contentReference[oaicite:11]{index=11}
- alt-text: describe chart in plain language for screen readers :contentReference[oaicite:12]{index=12}
