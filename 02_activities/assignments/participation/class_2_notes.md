## Choosing the Right Visualization

- Not all visualizations are neutral
- Even if data is correct, design choices affect interpretation
- Visualization = rhetorical (we make choices)
- Two gun violence examples:
  - One emotional (dark background, dramatic)
  - One more "neutral" (bar chart style)
- Both not dishonest
- But both guide viewer in different ways

→ So neutrality is kind of impossible

---

## Important things to think about:

- Purpose (persuade? compare? explore?)
- Audience (who is looking at it?)
- Medium (print, web, presentation?)

Different purpose = different design choices

---

## Reproducibility

- Means someone else can recreate your result
- Must include code + data
- Ethical + practical
- Helps with transparency
- Important in research

Ways to make visualization reproducible:
- Work programmatically (matplotlib, not Illustrator)
- Write in plain text
- Comment code
