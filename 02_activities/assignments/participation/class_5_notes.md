# Class 5 – beyond matplotlib

ok so matplotlib is not the only thing

---

## seaborn

- built on top of matplotlib
- looks nicer automatically
- easier to map variables like x= y= hue=
- used tips dataset (built in)
- hue = colour by category
- style = marker type
- pairplot = makes a bunch of plots fast
- relplot = split into panels

basically seaborn = less manual work

---

## plotly

- interactive
- hover shows values
- can zoom
- syntax different (add_trace etc)
- feels more web/app vibes

static vs dynamic:
- static = png (simple story)
- dynamic = interactive (more exploring)
- dynamic cool but maybe confusing if too much

---

## wordcloud

- makes text cloud from big text
- bigger word = shows up more
- kind of summary of text visually

---

## venn diagrams

- show overlap of 2 groups
- default shows counts
- can change labels to show actual items
